# student-success-risk-pipeline
A machine learning project that analyzes academic and demographic data to identify students who may be at risk of dropping out

## Team Project
This project was developed collaboratively as part of a group project. My primary contributions included machine learning model development, model evaluation, and analysis of model performance.

## Project Overview
The goal of the project was to build a classification pipeline that could predict student dropout risk using academic and demographic features.

The dataset contained:
-  4,424 student records
-  37 features
-  Academic, demographic, and enrollment-related variables

We compared multiple machine learning models to determine which approach performed the best for identifying students at risk

## Models Evaluated

-  Logistic Regression
-  Decision Tree
-  Random Forest

Model performance was evaluated using

-  Accuracy
-  Precision
-  Recall
-  F1-score

## Best Model 

The tuned Random Forest model produced the strongest overall performance:

-  Accuracy: 85.3%
-  Precision: 86.9%
-  F1-score: 77.1%
